Here is the definition of an arguement:

An arguement is a value we pass into the function as its input when we call the function.
We use arguements so we can direct the function to do different kinds of work when we call it at different times.
We put the atguements in parentheses " () " after the name of the function

The variables inside the function's parentheses can also be called " parameters ".
Here is an example:

def greet ( lang ) :
    if lang == 'en' :
        print ( 'Hello! ')
    elif lang == 'es' :
        print ( '¡Hola! ' )
    elif lang == 'ru' :
        print ( 'Привет! ' )
    else :
        print ( 'Hello! ' )

greet ( 'en' )
greet ( 'es' )
greet ( 'ru' )

Output:

Hello! 
¡Hola! 
Привет!

The three greetings there are Return values.
The computer does some computations in the function and returns a value after executing the function.
There is a function for returning values called the " return " funtion but it is not necessary in Python.
A " fruitful " function is one that produces a result ( or a return value )
Here is our program using the " return " function:

def greet ( lang ) :
    if lang == 'en' :
        return 'Hello'
    elif lang == 'es' :
        return '¡Hola'
    elif lang == 'ru' :
        return 'Привет'
    else :
        return 'Hello'

print ( greet ( 'en' ), 'John! ' )
print ( greet ( 'es' ), 'José! ' )
print ( greet ( 'ru' ), 'Михаил! ' )

Output:

Hello John! 
¡Hola José! 
Привет Михаил!
