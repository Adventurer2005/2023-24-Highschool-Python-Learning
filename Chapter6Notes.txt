A " String " data type is a sequence of characters.
A string literal uses quotes ' Hello ' or " Hello ".
For strings, " + " means " concatenate ".
If a string contains numbers, it is still a string.
Numbers can be converted from a string into an integer using the " int() " function.

It is perferred to read data using strings and then parse and convert data as needed.
Raw input from the user is almost always going to be a string data type.

We can get any single character in a string using an index specified in square brackets " [] ".
The index value is an integer value starting at zero " 0 ".
The index value can be an expression that is computed.

Example:

print ( letter )

" Slicing " is a meathod used to take portions of a string and slice it off.
A section of a string can be observed using a colon operator " : " in the square brackets " [] ".
The first number in the colon is the starting number and the last number is the letter up to it but not after it.
If the second number is beyond the end of the string, it stops at the end.

Example:

time = '14:51'
print ( time [ 0 : 2 ] )
print ( time [ 3 : 5 ] )
print ( time [ : ] )

Output:

14
51
14:51

String concatenation is a meathod of adding two strings of text together.
The plus operator " + " is used to concatenate the strings.

Example:

a = 'Hello'
b = a + 'There'
print ( b )
c = a + ' ' + 'There'
print ( c )

Output:

HelloThere
Hello There

As can be seen, the concatenations, string " b " does not have a space between the two letters since the concatenation using the plus operator does not add a space.
In variable " c ", there is a space since it was added as a separate string in the concatenation.
The comma " , " can be used to concatenate strings but I have only found that it works best in the " print() " function.

White space can be removed using " .lstrip() " or " .rstrip() " to remove the space on either the left or the right of the string.
The " .strip() " ending can be used to do so on both sides.
" .startswith() " can be used to test if a string with words starts with a word, an not a letter.

Parsing and extracting text from a string can be useful whenever there are signs around the string that is searched for.
An example is if a number is searched for in a text.

data = "This is lane #214."
before = data.find ( '#' )
after = data.find ( '.', before )
number = data [ before + 1 : after ]
print ( number )

Output:

214
