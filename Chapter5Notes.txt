Lesson 1:

A while loop is a meathod for iteration in Python.  
The function " while " is used to start a while loop.
After the " while " function a condition follows which is either true or false.
If the condition is true then the while loop will continue to loop until the condition is false.
Here is an example:

n = 5
while n > 0 :
    print ( n )
    n = n - 1
print ( 'finish ' )
print ( n )

Output:

5
4
3
2
1
finish
0

We can see in this program that n decreases every time the while loop runs until n = 0.  The loop ended whenever n = 0.
An infinite loop happens whenever the condition in a while loop will never be false.
Here's an example:

x = 0
while x = 0 :
    print ( x )

The output is infinite here.
A zero trip loop never runs.
Here is an example:

x = 0
while x > 0 :
    print ( 'yes' )
print ( 'no' )

Output:

no

To break out of a loop the " break " function is helpful to do this.

print ( 'say yes. ' )
while True :
    line = input ( '> ' )
    if line == 'yes' :
        break
    print ( line )
print ( 'good job. ' )

Output:

say yes. 
> [ yes ]
good job. 

The while loop that is used here is called an Indefinite loop.
This type of loop goes on until the condition is false.

Lesson 2:

We use the " for " function to run a " Definite Loop ".
The Definite loop runs a finite set of things.
We can write a loop to run a loop once for each item in a set using the Definite loop.
These loops execute an exact number of times.
Example:

for i in [ 5, 4, 3, 2, 1 ] :
    print ( i )
print ( 'finish. ' )

Output:

5
4
3
2
1
finish. 

Here's a definite loop with strings:

greetings = [ 'good morning! ', 'good afternoon! ', 'good evening! ' ]
for greeting in greetings :
    print ( 'Hello,', greeting )
print ( 'finished ' )

Output:

Hello, good morning! 
Hello, good afternoon! 
Hello, good evening!
finished

A simple definite loop have iteration varables that change through a loop.
The variable goes through the list shown in the square brackets " [] ".
It checks whether the loop is complete or incomplete; if it is incomplete, it continues on until it is complete and then finishes.
We use the " in " operator to show that the sequence is in the variable.
The loop iterates as many times as there are variables in the sequence.

Lesson 3:

Loop Idioms are patterns that we use to construct loops.
It helps to make " smart " loops.
Here's an example of a practical loop: finding the greatest number in a list.
Here is a meathod for doing that:

current_max = 0
print ( 'Before:', current_max )
for number in [ 9, 41, 12, 3, 74, 15 ] :
    if number > current_max :
        current_max = number
    print ( current_max, number )
print ( 'Result:', current_max )

Output:

Before: 0
9 9
41 41
41 12
41 3
74 74
74 15
Result: 74

We see that on the left side the program remembers the current largest number and at the end of the loop, it finishes with the greatest number observed in the set compared to each other number.

We can filter in a loop by using the " if " statement inside of a definite loop.
Here is an example:

print ( 'We will check to see if our list has the number [ 3 ].' )
found = False
print ( 'Start:', found )
for number in [ 9, 41, 12, 3, 47, 15 ] :
    if number == 3 :
        found = True
    print ( number, found )
if found == False :
    result = '3 does not exist in the list.'
if found == True :
    result = '3 exists in the list.'
print ( 'End:', found, result )

Output:

We will check to see if our list has the number [ 3 ]:

9 False

3 True

End: True 3 exists in the list.

What we can also do is use a " None " type variable.
This variable does not store a numberical value.  It is almost like we call the variable but do not assign it a value.
This variable by assigning a variable to " None " written as such with a capital " N ".
Here is my meathod for finding the largest and smallest values in the list using the None type:

largest = None
smallest = None
print ( 'Start:', largest, smallest )
for number in [ 9, 41, 12, 3, 47, 15 ] :
    if largest is None :
        largest = number
    elif number > largest :
        largest = number
    if smallest is None :
        smallest = number
    elif number < smallest :
        smallest = number
    print ( largest, smallest, number )
print ( 'Finish:', largest, smallest )

Output:

Start: None None
9 9 9
41 9 41
41 9 12
41 3 3
47 3 47
47 3 15
Finish: 47 3

One thing to note here is that the if statements used here are checking whether our variable is assigned by asking if are variable is None.
Before we compare values of our variables we MUST assign our variable a number or else the code will not run and we will get an error code.
